    - Self-test fixture: a page with 3 @font-face blocks, each with a local /_astro/fonts/*.woff2 src and a unicode-range, 3 fallback faces with src local() and size-adjust, and 1 font preload link. Expected: passes with --max 3.
    - The same page with 4 distinct WOFF2 URLs. Expected: "over budget: 4 > 3".
    - A WOFF2 src on fonts.gstatic.com, or any absolute http(s) font URL. Expected: "third-party font host".
    - A WOFF2 @font-face without unicode-range. Expected: "not subset".
    - Fewer size-adjust fallback faces than distinct WOFF2 families. Expected: "missing metric-matched fallback".
    - Two font preload links, or zero when the page has WOFF2 faces. Expected: "preload count".
    - --distinct across two pages that share a WOFF2 URL. Expected: "pairings share font files".
    - --max 0 on a page with no @font-face and no preload. Expected: passes (the index case).
  </behavior>
  <action>
An ESM Node 24 script that imports only node: built-ins. Usage: `node scripts/check-fonts.mjs [--max N] [--distinct] [--dist DIR] <page.html>...` (defaults: max 3, dist `dist`), or `--self-test`.

For each page:
- Gather CSS text from every inline `style` element and every `link rel="stylesheet"` whose href starts with "/" (read from under the dist directory). Split it into @font-face blocks with a regex.
- For blocks whose src names a .woff2, record the URL and the family. Assert the URL is root-relative and exists under dist, the block has unicode-range, and font-display is swap or optional.
- Count fallback faces: blocks whose src uses local() and that contain size-adjust. Assert that count is at least the number of distinct WOFF2 families.
- Count `link` tags with rel preload and `as="font"`. It must be exactly 1 when the page has any WOFF2 face, and 0 otherwise.
- Fail if the page HTML or its CSS mentions any of fonts.googleapis.com, fonts.gstatic.com, cdn.jsdelivr.net or api.fontsource.org.
- Print one line per page: path, WOFF2 count, total WOFF2 KB (from fs.statSync), preload count.

With --distinct, fail when any two pages share a WOFF2 URL.

--self-test runs every behavior case above on in-memory strings. It prints "self-test: <passed>/<total>" and exits 0 only when all pass. Each bad case asserts at least one violation, so a no-op rule fails the self-test.

The final line is "check-fonts: OK" (exit 0) or "check-fonts: <n> violation(s)" (exit 1).
  </action>

    <fails_when>non-zero exit; "self-test: x/y" with x below y; or no "check-fonts: OK" final line for the a page</fails_when>
